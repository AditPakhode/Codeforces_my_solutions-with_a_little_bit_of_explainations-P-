# Codeforces solution
**This is my repo to discuss all of the problems I have solved in Codeforces.**


## Format

**The format is as follows: -**
- The solution named as "<Question_number>_solution.md". Explains all of my thought process.
- The failed submissions as "<Question_number>_attempt<attempt_number>.cpp". Are the in-between process that got me to the correct solution.
- The correct solution as "<Question_number>_submitted<solution_number>.cpp". Which is the accepted answer if there are multiple I will try to solve it by all the solutions.
